# Janhavi Beley Portfolio — Version 24

A single-page portfolio, ready for GitHub Pages. All writing, experience, awards and links are editable directly in `index.html`. No localhost, build process or JavaScript fetch requests are required.

## Edit content

- Open `index.html` in VS Code or a text editor.
- Change the About paragraph in the HTML.
- Find `const content=` near the end of the file to edit experience, projects, Recognition and Writing.
- Change colours in the CSS variables at the top of `index.html`.
- Keep the `assets` folder alongside `index.html`.

## Publish

Upload `index.html` and `assets/` to the root of your GitHub Pages repository. Under Settings → Pages, select `main` and `/(root)`.

The Harvard WECode award links to your published Medium article. The SACNAS entry has no direct post URL because one has not been verified; add the original award-post URL to its `url` field when available.
